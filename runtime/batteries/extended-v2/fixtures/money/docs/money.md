# amount_to_cents 契约

输入为字符串，先去掉两侧的 ASCII 空格（U+0020）。合法正文是 ASCII 数字组成的整数，或整数加小数点和一至两位 ASCII 小数数字。允许前导零。

- 金额范围：0 至 9999.99，含端点。
- 返回整数分，精确转换；例如 `"0.29"` 返回 29，`" 12.3 "` 返回 1230。
- 以下抛 ValueError：负数、正号、指数写法、NaN/Infinity、超过两位小数、空串、单独小数点、缺少整数部分、非 ASCII 数字、内部空格、制表符或换行。
- 非字符串抛 TypeError。不得默默四舍五入输入或以二进制浮点误差少算一分。
