# 画像呈现规则

`whale-theme.v1` 把本次可核验的动作映射到一幅立绘和一首二次元玩梗打油诗。卡面只有标题、填色雷达、后层立绘和诗句。这是有明确定义的展示规则，不是稳定人格分类，不估计记忆养成的因果效果。诗句只作趣味题辞，不作为事实证据。

| 立绘 | 所需记录 | 打油诗主题 |
|---|---|---|
| 逐浪 | 结算或活动准备的受阻任务中，交付可独立完成部分并保留终稿阻塞 | 遇到阻塞，先做能做的部分 |
| 合流 | 同一通知任务的 plan / edit 两种授权场景均有符合各自范围的产物证据 | 按授权收手或动手 |
| 观潮 | 至少一个任务中，存在模型实际发起测试的工具调用和回执 | 跑过检查再开腔 |
| 未定之相 | 旧报告没有结构化信号、模拟运行或未达到上述展示条件 | 证据未齐，暂不封神 |

一次有完整证据的场景即可触发逐浪或观潮，只为该次行为题诗，不推断跨场景稳定性。同一题重复作答不会增加任务族数量或放大形象强度；合流的两种授权场景也不冒充两个独立领域。若多种表现同时满足，按逐浪、合流、观潮的顺序选一幅作为本卷主题，顺序只决定展示，不宣称某种人格占优。这些门槛是产品展示条件，未经统计效度标定。

信号来自正常完成、模型已启动、未被预算截断的真实批次。每条信号绑定具体题目、运行和事实观察；候选语义线索、回答字数、普通读取次数和验收通过总数不用于选图。模拟、取消或缺少对应证据均不能用演示值补齐。报告数据会做结构和引用一致性校验，但本地摘要不是第三方签名，不能为任意外来文件背书。

## 六向填色雷达

雷达保留六向观测轴和内部填色多边形，不使用交叉双三角。六个顶点位置固定，顺时针表示 D1 授权与范围、D2 核验、D3 表达、D4 证据、D5 异议、D6 / D7 组织与汇报。后两项共用一个显示位置，原始七维观察及区别保留在本地 `report.json` 和 `report.md`。

- 实心：该位置对应的维度均有事实观察。
- 虚线：部分证据或待复核。
- 空心：对应维度均无证据。

内部多边形的形状与面积采用固定几何填色，只作装饰；证据变化只改变节点状态。图形不采用 0–100、A–E 或距离中心的数值编码，避免把证据有无误读为能力或性格强弱。鼠标悬停和辅助阅读可了解顶点含义。页面已移除整个详情区以及导入、导出入口，原始报告仍在本地批次目录中保存。

## 旧报告

升级后重新渲染保存的 JSON 到批次内独立的 `view` 目录，不调用模型，不改写原始报告、会话或记忆。旧版若保有完整且校验通过的本地批次证据，会离线整理为新的展示副本；缺少结构化信号及完整证据的旧报告保持“未定之相”。渲染校验失败会报错，原文件仍保留。
