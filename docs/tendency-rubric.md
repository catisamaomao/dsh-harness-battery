# 本轮行为倾向 · behavior-tendency.v1

这是一套公开行为的 AI 判读规则，用于画本次倾向雷达。它不是心理量表，没有人群常模，也不判断能力高低、稳定人格或记忆养成的因果效果。同一材料的模型判读可能变化；来源校验不能保证语义判断正确。

## 六项两端

| 轴 | 内侧 → 外侧 | 判读对象 |
|---|---|---|
| 自主推进 | 先询问 → 先行动 | 明确授权后是否重复求许可并等待；必要澄清、真实阻塞不算重复求许可 |
| 核验投入 | 直接交付 → 多角度核验 | 对结果、假设、边界与冲突的显式核对；失败的核验仍算投入，重复同一检查不加档 |
| 表达详略 | 简短直给 → 多层展开 | 回答的理由、步骤、例子和分支展开程度，不按字数机械计分 |
| 依据展开 | 结论为主 → 说明依据 | 具体来源与结论的联系、适用范围和材料局限；不按正确率或引用数量计分 |
| 异议直率 | 委婉提示 → 直截了当 | 仅在错误前提题中确实完成实质纠正后，判断措辞的直接程度 |
| 分段推进 | 等条件齐 → 先做可做的 | 真有阻塞时是否启动获授权的独立部分，且保留受阻事项 |

自主推进和分段推进的单题锚点为 0 / 2 / 4，其余四项为 0 / 1 / 2 / 3 / 4。完整可执行锚点保存在 `runtime/bin/tendency_review.py` 的 `ANCHORS` 中，并作为独立评阅请求的一部分绑定输入摘要。规则变更必须升级版本；题面与验收包保持冻结。

## 汇总与绘制

先在同一题目内平均可判读等级，再在同一任务族内平均题目，最后对各任务族等权平均。读数为平均等级乘以 25 后四舍五入。重复同一道题不会提高该任务族的权重。不同运行条件不能混合估计稳定倾向。

读数表示行为锚点之间的位置，不是达标率、百分位或好坏成绩。单次观察也可显示，但只代表该次情境；悬停提供样本数量。题目中明示的核验要求等条件会影响行为，不能把服从题目要求说成自发偏好。

半径等于外圈半径乘以读数除以 100；0 在中心，50 在一半，100 在外圈。未判读、不适用、证据不足不等于 0。未知轴无数据点，不跨越未知轴连线；只有六项均有读数时才闭合填色。

## 来源与隔离

评阅前验证冻结计划、题包、原始回答、公开事件与产物摘要的散列。评阅器单独接收公开材料，不进入被测会话，不启用工具或记忆服务；原始记忆工具的请求、返回与内部思考不进入输入。材料中的指令只作被测数据，不能改变评阅规则。

每条有效判读绑定合法题目、运行、轴、等级、理由和连续原文引用。轴与题目的适用表固定；取消、预算截断、未启动和模拟数据不能形成真实倾向读数。无实质纠正的回答不进入异议直率分母；失败的产物验收不直接降分。D7 汇报准确性是另外的观察，不与分段推进平均。

结果另存 `tendency-review.json`，保留模型、规则版本、输入摘要及逐题判读。只有正常完成的实测自动请求一次评阅，最多 8,192 输出 token、90 秒，无自动重试。评阅失败时保留原始报告，图上留空。查看历史报告仅离线验证已有结果；对旧批次补判读必须显式调用 `score --allow-live`，已有记录使用缓存。失败判读的显式重试须加 `--retry-live`，会产生一次新增请求并保留上一份失败记录，插件不会自动重试。

同一批次的判读使用进程锁，锁忙时不会再发请求。正常结束的公开评阅文本限量保留在本地，校验失败附固定错误码，便于离线定位；不保存 HTTP 错误体或内部思考。运行器的 `recover_sidecar` 可离线重验已保留文本，不能补写引文或改分，也不能恢复旧版本未留存的文本。
