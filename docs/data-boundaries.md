# 数据与运行边界

安装不会启动测试。页面读取题库、环境状态及本插件保存的历史，不读取当前会话内容；开始操作才创建并运行测试批次。

本机数据存放在 `~/Library/Application Support/DeepSeek Harness/plugins/dsh-harness-battery`，与安装包分离。目录使用当前用户权限保护。报告可能包含模型答复、工具结果以及被模型引用的个人记忆，属于用户自己的本地数据，不会随插件上传到 GitHub。

默认使用空记忆。选择 Memorix 后通过 SQLite 只读备份制作副本，在独立 HOME/DSH_HOME 和工作区内运行，每题重建环境。原记忆数据库不会被本插件写入；测评结果不会回灌。用户在页面明确选择包含记忆并开始真实测试，才授权本次测评对官方 DeepSeek 提供商使用这些检索结果。

提供商凭据只由受控宿主桥接使用，不进入被测进程或题目工作区。模型通过固定官方端点调用；被测进程树的直接网络权限关闭。私有批次默认留在本机，不额外发送遥测，也不自动导出。

插件的 HTTP 接口只接受本地宿主来源，修改操作需要页面取得的进程令牌及 JSON 请求；不提供任意命令执行或任意路径文件浏览。报告只能从本插件批次目录读取，在隔离 iframe 中展示。

取消会终止当前受控执行并保留已收集记录。它不能撤销已经发出的请求或退还已产生的提供商用量。没有正常完成的作答不作为性格失败计入。

本地独立会话可减少测评对日常状态的影响，但题目仍会影响当次上下文；模型提供商的服务端数据政策由提供商决定。该隔离不等于“零影响”，也不证明被测条件与日常 desktop 完全相同。

不能从公开理由推断隐藏思维；引用规则不等于规则造成了选择；同族两题不是两个独立领域。题库扩展和软件验收不等于画像效度标定。原始回答、工具动作、产物检查与人工语义判断需要分开阅读。
